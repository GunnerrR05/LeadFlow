# LeadFlow

Sistema de gerenciamento de leads desenvolvido em Python.

## Funcionalidades

- Cadastro de leads
- Busca por telefone
- Atualização de leads
- Exclusão de leads
- Listagem de leads
- Interface gráfica com Tkinter
- Armazenamento em Excel (OpenPyXL)

## Tecnologias

- Python
- Tkinter
- OpenPyXL

## Como executar

```bash
python interface.py
```
