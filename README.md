# Zarken Leads

Sistema Zarken para gerenciamento de leads comerciais.

## Funcionalidades

- Cadastro, consulta, edição e exclusão de leads
- Busca por telefone
- Histórico de status e prioridades
- Follow-ups comerciais
- Dashboard para acompanhar os leads
- Exportação de dados
- Backups locais
- Interface gráfica com Tkinter

## Tecnologias

- Python
- Tkinter
- OpenPyXL
- PyInstaller

## Como executar

```bash
python main.py
```
