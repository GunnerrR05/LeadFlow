# Zarken Leads

Sistema Zarken para gerenciamento de leads comerciais.

## Funcionalidades

- Cadastro de leads
- Busca por telefone
- Atualização de leads
- Exclusão de leads
- Listagem de leads
- Interface gráfica com Tkinter
- Armazenamento em Excel (OpenPyXL)

## Tecnologias

- Python
- Tkinter
- OpenPyXL

## Como executar

```bash
python main.py
```
